# Z-Company Assets

This repository contains image assets for Z-Company.

## Pop Images

The `pop-images/` directory contains promotional and point-of-sale images.

### Usage

Images can be accessed via GitHub Pages:

```
https://tech0-swat.github.io/z-company/pop-images/[filename].png
```

### Available Images

- 40 PNG image files
- Format: Various sizes optimized for web display
- Naming convention: Product codes and identifiers

## GitHub Pages

This repository is configured to serve static assets via GitHub Pages.
